# Release assurance evidence v1

ActiveChain development releases may describe implemented behavior and test results, but may not
claim an independent audit, AML compliance, or regulator approval without evidence.

## Required evidence package

- signed role/jurisdiction matrix and compliance boundary;
- protocol/profile revisions, genesis identity, build provenance, and reproducible artifacts;
- operating-period logs for validators, RPC, faucet, screening, Travel Rule, monitoring, and
  incident response;
- deterministic vector results, formal-proof scope/assumptions, adversarial tests, and restart
  evidence;
- independent security and compliance engagement scope, findings, remediation, and sign-off;
- release decision, exceptions, residual risks, and owner acknowledgement.

Evidence is versioned and linked to the exact release commit. Missing, stale, or contradictory
evidence blocks the claim and may block a regulated-profile deployment. The absence of an external
engagement is reported plainly as “not independently audited.”
