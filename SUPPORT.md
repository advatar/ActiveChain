# Support

ActiveChain is maintained as a developmental open-source project. There is no guaranteed response
time or production support contract.

## Where to ask

- Use [GitHub Issues](https://github.com/advatar/ActiveChain/issues) for reproducible bugs,
  documentation problems, and scoped feature proposals.
- Use an existing issue when one already covers the same boundary.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for development and pull-request questions.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

When asking for help, include the commit, operating system and architecture, exact command, expected
behavior, actual behavior, and the smallest useful log excerpt. Redact credentials and personal
data. For testnet problems, include the chain/genesis identifier and whether the observation came
from finalized evidence or an unverified endpoint.

Maintainers may close broad, duplicate, unsupported, non-reproducible, or security-sensitive public
reports with a pointer to the appropriate process.
